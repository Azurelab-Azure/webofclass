隐私政策

Effective Date: 2026-10-01

PlanPeople 的核心理念是：你的数据，只属于你。 我们不仅承诺保护你的隐私，更从底层架构上杜绝了数据泄露的可能。

我们收集了哪些信息？

没有任何信息。 我们不收集、不读取、不上传您的任何个人数据。

  • 无需注册： 无需邮箱、手机号，下载后即可使用全部功能。
  • 无云端同步： 我们没有服务器来存储您的课表或成绩。
  • 无遥测数据： 不会在后台静默收集您的点击习惯或崩溃日志。

数据存储在哪里？

所有的课程、学生档案、成绩等数据，均以纯文本的 JSON 格式保存在您电脑的本地文件夹中（data/ 目录）。

您可以随时打开这些文件进行查看、备份或删除。只要您不删除该文件夹，您的数据就永远在您的硬盘里。

网络请求说明

PlanPeople 是一款完全离线的软件。它在后台运行时不会发起任何网络请求。只有当您主动点击“检查更新”或在“关于”页面访问 GitHub 链接时，才会连接到互联网。

第三方服务

本软件不使用任何第三方分析服务、广告 SDK 或支付接口。项目代码遵循 MIT 协议开源，您可以随时审查底层的网络行为。

数据销毁与迁移

卸载软件时，程序会自动清理运行时缓存，但会保留 data/ 文件夹以防您日后重装。若您需要彻底销毁数据，只需手动删除该文件夹即可，不留任何残留。

PlanPeople 是纯本地架构的坚持者。无论未来版本如何迭代，我们承诺始终保留离线可用的核心体验。
