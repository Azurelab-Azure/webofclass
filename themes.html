系统要求

项目要求
操作系统Windows 10 或 Windows 11
运行时.NET 10 Desktop Runtime
磁盘空间约 150 MB
网络不需要。除可选的新闻功能外，完全离线可用

安装说明

安装版

  1. 下载 .exe 文件
  2. 双击运行，按提示完成安装
  3. 首次启动会在程序目录生成数据文件

绿色版

  1. 下载 .zip 文件
  2. 解压到任意目录，建议不要放在 C 盘根目录
  3. 双击 CourseApp.exe 即可运行
  4. 删除目录即完全卸载

数据位置

所有数据保存在程序目录下的 JSON 文件中。复制该目录即可完成备份。
