# 快速开始

欢迎使用我的课表。这篇文档帮你在 3 分钟内上手。

## 它是什么

**我的课表** 是一款 Windows 桌面应用，为教师、学生、班主任与家长设计。

- **无服务器**：没有账号系统，没有云端同步，没有分析服务
- **纯本地**：所有数据保存在你自己的电脑上
- **20 种语言**：简体、繁体、英、日、韩、法、德、西、俄、阿等
- **4 种主题**：亮色、暗色、通透、清新

## 第一步 · 下载安装

前往 [下载页](download.html) 获取 Windows 安装包。

系统要求：

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 或 Windows 11（64 位） |
| 运行时 | .NET 10 Desktop Runtime |
| 磁盘空间 | 约 150 MB |
| 网络 | 不需要 |

## 第二步 · 首次启动

打开程序后，会自动在安装目录生成一个 `data` 文件夹，里面保存 JSON 格式的数据文件。

接下来你可以：

1. 在 **课程表** 里录入你的课程
2. 在 **学生管理** 里导入班级名单
3. 在 **成绩分析** 里记录第一次考试

## 第三步 · 个性化

右上角可以切换：

- **4 种主题**：点圆点即切换
- **20 种语言**：设置里选择
- **灵动岛**：开启今日课程悬浮窗

> 提示：所有数据保存在本地，不需要登录，也不会联网。

## 快捷操作

| 操作 | 快捷键 |
|------|--------|
| 新建课程 | Ctrl + N |
| 搜索 | Ctrl + F |
| 切换主题 | Ctrl + T |
| 备份数据 | Ctrl + B |
| 打印课表 | Ctrl + P |
