# 学生管理

学生管理功能帮你维护班级名单、座位表与个人档案。

## 三个视图

1. **名单视图**：所有学生的列表，支持排序、筛选、搜索
2. **座位表视图**：可视化排座，拖拽调整
3. **个人档案视图**：单个学生的详细信息

顶部切换按钮可以在三个视图之间快速切换。

## 添加学生

### 单个添加

点击「添加学生」按钮，填写以下信息：

| 字段 | 说明 |
|------|------|
| 学号 | 学籍号或班级编号 |
| 姓名 | 学生姓名 |
| 性别 | 男 / 女 |
| 座位 | 如「3 排 2 座」 |
| 出生日期 | 可选 |
| 家长 | 家长姓名 |
| 家长电话 | 联系方式 |
| 住址 | 家庭住址 |
| 照片 | 支持上传 |
| 备注 | 补充说明 |

### 批量导入

支持从 Excel 或 CSV 导入整个班级。

CSV 格式示例：

学号,姓名,性别,座位,家长,家长电话
20260101,张三,男,3-2,张先生,13800138000
20260102,李四,女,3-3,李女士,13900139000


导入时程序会：

1. 自动检测列名
2. 提示格式错误
3. 预览导入结果
4. 一次性写入

## 座位表

座位表视图是一个可视化网格：

- 拖拽学生到任意位置
- 双击学生换座位
- 支持设置排数、列数、过道
- 支持导出为图片

导出的座位表可以贴到教室墙上。

## 学生档案

点击任意学生，进入个人档案页：

- 基本信息
- 考勤记录
- 成绩记录
- 家长联系方式
- 备注

## 考勤

在名单视图里，每个学生右侧有考勤按钮：

| 状态 | 说明 |
|------|------|
| 出勤 | 默认状态 |
| 缺勤 | 未到校 |
| 请假 | 有请假条 |
| 迟到 | 迟于上课时间 |

考勤数据会汇总到统计面板。

## 搜索与筛选

- **按姓名**：输入姓名关键词
- **按学号**：输入学号数字
- **按性别**：筛选男生或女生
- **按座位**：筛选某排某列

## 导出

支持导出：

| 格式 | 内容 |
|------|------|
| CSV | 全部学生信息 |
| PDF | 名单表，A4 排版 |
| PNG | 座位表图片 |
| JSON | 备份用 |
