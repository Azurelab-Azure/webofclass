# 成绩分析

成绩分析功能帮你快速录入、统计、分析学生成绩。

## 新建考试

1. 点击「新建考试」
2. 填写考试信息：

| 字段 | 说明 |
|------|------|
| 考试名称 | 如「期中考试」 |
| 科目 | 如「数学」 |
| 日期 | 考试日期 |
| 满分 | 默认 100 |
| 及格线 | 默认 60 |

3. 保存后进入录入界面

## 快速录入

录入界面是一个表格，每行一个学生：

| 学号 | 姓名 | 分数 |
|------|------|------|
| 20260101 | 张三 | 86 |
| 20260102 | 李四 | 60 |
| 20260103 | 王五 | 26 |

### 键盘操作

- `Tab` 跳到下一格
- `Enter` 保存并跳到下一个学生
- `Esc` 取消当前输入
- 输入数字后自动校验范围

### 导入成绩

从 Excel 或 CSV 导入：

学号,分数
20260101,86
20260102,60


程序会按学号自动匹配学生。

## 成绩看板

录入完成后，看板显示：

| 指标 | 说明 |
|------|------|
| 平均分 | 全班分数平均值 |
| 最高分 | 全班最高分数 |
| 最低分 | 全班最低分数 |
| 及格率 | 分数 ≥ 及格线的人数占比 |
| 优秀率 | 分数 ≥ 满分 × 0.85 的人数占比 |

### 柱状图

看板下方是分数分布的柱状图：

- X 轴：分数段（0-59、60-69、70-79、80-89、90-100）
- Y 轴：人数
- 绿色：及格段
- 红色：不及格段

## 排名

成绩表下方显示完整排名：

| 排名 | 姓名 | 分数 |
|------|------|------|
| 1 | 张三 | 98 |
| 2 | 李四 | 95 |
| 2 | 王五 | 95 |
| 4 | 赵六 | 88 |

支持并列名次。

## 成绩趋势

在「趋势」标签页，可以看到：

- 按学期追踪每个学生的成绩变化
- 按科目对比班级平均分
- 进步榜与退步榜

## 导出

| 格式 | 内容 |
|------|------|
| PDF | 成绩单，可直接打印发给家长 |
| CSV | 原始数据，可导入其他软件 |
| PNG | 看板截图 |
| JSON | 备份用 |

PDF 成绩单包含：

- 考试名称与日期
- 全班排名表
- 统计指标
- 可选：每个学生的详细成绩

## 多科目管理

一个学期通常有多门考试。我的课表支持：

- 按科目分类
- 按时间排序
- 跨科目对比
- 综合评分
