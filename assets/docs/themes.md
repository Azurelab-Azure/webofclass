# 主题

我的课表提供 4 种界面主题，一键切换，立刻生效。

## 四种主题

| 主题 | 底色 | 适合场景 |
|------|------|----------|
| 亮色 | 白色 | 白天、光线充足 |
| 暗色 | 深灰 | 夜间、投影环境 |
| 通透 | 冷调浅蓝 | 白天、清爽现代 |
| 清新 | 自然绿调 | 长时间使用、护眼 |

## 怎么切换

### 桌面软件

1. 打开 **设置**
2. 进入 **外观 → 主题**
3. 选择四种主题之一

或者使用快捷键 `Ctrl + T` 循环切换。

### 官网

本官网也提供四种模式：

- 右上角 4 个圆点，点击即切换
- 月亮与太阳图标切换亮暗

## 主题对比

### 亮色

默认模式。白底黑字，长时间阅读不累。适合白天、光线充足的教室和办公室。

### 暗色

夜间模式。深灰底浅字，减少屏幕刺激。适合夜间备课、投影环境。

### 通透

冷色调浅蓝。清爽、现代，适合白天使用。适合长时间盯着屏幕的人。

### 清新

自然绿调。柔和、护眼，适合长时间使用。适合教室环境。

## 自定义颜色

高级用户可以在 `config.json` 里自定义主题色：

```json
{
  "theme": "light",
  "customColors": {
    "accent": "#0067C0",
    "text": "#0A0A0A",
    "background": "#FFFFFF"
  }
}
```

修改后重启程序生效。

## 存储位置

官网的主题选择保存在浏览器 LocalStorage 中，键名为 theme 与 ui。

桌面软件的主题选择保存在程序目录下的 config.json 中。
