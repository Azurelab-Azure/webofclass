# 安装与卸载

## 下载

前往 [下载页](download.html) 获取 `.exe` 安装包。

当前稳定版本是 **v1.0.0**，测试版是 **v1.1.0-beta.1**。

## 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 或 Windows 11（64 位） |
| 运行时 | .NET 10 Desktop Runtime |
| 磁盘空间 | 约 150 MB（含运行时） |
| 内存 | 建议 4 GB 以上 |

如果系统缺少 .NET 10 运行时，安装程序会自动检测并提示下载。

## 安装步骤

1. 下载 `MyClassroom-Setup-1.0.0.exe`
2. 双击运行
3. 按提示完成安装
4. 首次启动会在安装目录生成数据文件

安装位置默认为：
C:\Users<用户名>\AppData\Local\MyClassroom


安装时也可以自定义路径。

## 卸载

### 通过 Windows 设置

1. 打开 **设置 → 应用 → 已安装的应用**
2. 找到 **我的课表**
3. 点击 **卸载**

### 手动清理

程序安装目录下的 `data` 文件夹保存你的数据。卸载时不会自动删除，需要手动清理。

> 如果你以后想重装继续用，建议保留 `data` 文件夹。

## 数据文件位置

| 文件 | 内容 |
|------|------|
| `config.json` | 主题、语言、窗口位置 |
| `schedule.json` | 课程表数据 |
| `students.json` | 学生名单与档案 |
| `grades.json` | 成绩数据 |

所有文件都是纯文本 JSON，随时可以用记事本打开查看。

## 测试版说明

测试版（Beta）包含即将发布的新功能，但可能有 Bug。

- 版本号形如 `1.1.0-beta.1`

下载测试版前，我们请你先给项目点个 Star。这是自愿的，不会被强制验证。

## 常见问题

**Q：安装时提示缺少 .NET 运行时怎么办？**

A：点击提示中的链接，从微软官网下载 .NET 10 Desktop Runtime，安装后再重新运行安装程序。

**Q：可以装在 U 盘里吗？**

A：可以。安装时选择 U 盘作为安装路径，数据文件会跟随程序目录。拔掉 U 盘后无法运行。

**Q：安装后找不到程序在哪？**

A：开始菜单搜索「我的课表」，或者在安装目录找 `MyClassroom.exe`。
