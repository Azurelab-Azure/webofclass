# 课程表

课程表是我的课表的核心功能。它支持周次、单双周、特殊节次，一屏看全整个学期的安排。

## 界面结构

课程表界面分四部分：

1. **顶部工具栏**：切换周次、显示今日、搜索
2. **星期栏**：周一至周日
3. **节次栏**：左侧显示第 1 节到第 12 节
4. **课程格**：每个格子对应一节课

## 添加课程

### 方法一 · 双击空格

在课程表里双击任意空白的格子，弹出「新建课程」对话框。

### 方法二 · 快捷键

按 `Ctrl + N` 打开新建对话框。

### 方法三 · 从模板导入

设置里有「导入模板」，可以从 CSV 或 Excel 导入整个学期的课程。

## 课程字段

| 字段 | 说明 | 必填 |
|------|------|------|
| 课程名称 | 如「高等数学」 | 是 |
| 教师 | 授课老师姓名 | 否 |
| 教室 | 上课地点 | 否 |
| 周次 | 第 1-20 周 | 是 |
| 节次 | 第 1-12 节 | 是 |
| 单双周 | 全周 / 单周 / 双周 | 否 |
| 颜色 | 课程的显示颜色 | 否 |
| 备注 | 补充说明 | 否 |

## 周次设置

我的课表支持三种周次模式：

### 全周

每周都上，从开学到期末。

### 单周

只在第 1、3、5、7、9、11 周等单数周上课。

### 双周

只在第 2、4、6、8、10、12 周等双数周上课。

单双周在**课程表显示**和**今日课程**里都会自动过滤。

## 特殊节次

有些课不在常规节次，比如：

- **早自习**：7:30 - 8:00
- **午休**：12:00 - 14:00
- **晚自习**：19:00 - 21:00

在设置里可以自定义节次时间段，最多支持 12 节。

## 今日课程

打开程序时，首页会显示：

- 今天是星期几
- 今天有几节课
- 每节课的名称、时间、教室
- 下节课还有多久

## 灵动岛

在设置里开启「灵动岛」后，桌面会显示一个悬浮窗，实时显示：

- 正在上的课
- 剩余分钟数
- 下节课预告

灵动岛可以拖动到屏幕任意位置，也可以固定。

## 打印课表

按 `Ctrl + P` 或点击工具栏的打印按钮：

- 支持 A4 横向与纵向
- 可选黑白色或彩色
- 可导出为 PDF 或图片

## 搜索

按 `Ctrl + F` 打开搜索框，输入课程名或教师名，匹配结果会高亮显示。

## 导出

工具栏的「导出」按钮支持：

| 格式 | 用途 |
|------|------|
| PNG 图片 | 发到群里 |
| PDF | 打印 |
| CSV | 导入其他软件 |
| JSON | 备份数据 |
