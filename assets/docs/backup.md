# 备份与恢复

我的课表所有数据保存在本地 JSON 文件。备份很简单，复制文件即可。

## 数据文件

| 文件 | 内容 |
|------|------|
| `config.json` | 主题、语言、窗口位置 |
| `schedule.json` | 课程表数据 |
| `students.json` | 学生名单与档案 |
| `grades.json` | 成绩数据 |

所有文件都位于程序目录下的 `data` 文件夹。

## 备份方法

### 方法一 · 复制文件夹

最简单的方法：

1. 找到程序目录
2. 复制整个 `data` 文件夹
3. 粘贴到 U 盘、云盘或另一个硬盘

### 方法二 · 内置备份

在程序里：

1. 打开 **设置 → 数据**
2. 点击 **备份数据**
3. 选择保存位置
4. 生成一个 `.zip` 备份包

### 方法三 · 自动备份

在设置里可以开启：

- **每天备份**：每天首次启动时生成一份备份
- **保留份数**：最多保留 30 份
- **备份位置**：自定义目录

自动备份文件命名格式：
backup-2026-10-06-0930.zip


## 恢复方法

### 从文件夹恢复

1. 关闭程序
2. 把备份的 JSON 文件放回 `data` 文件夹
3. 重启程序

### 从 zip 恢复

1. 打开 **设置 → 数据**
2. 点击 **恢复数据**
3. 选择 `.zip` 备份包
4. 程序会提示是否覆盖当前数据
5. 确认后重启

## 跨设备迁移

想从一台电脑迁到另一台？

1. 在旧电脑上备份 `data` 文件夹
2. 把文件夹拷到新电脑
3. 在新电脑上安装我的课表
4. 用备份的 `data` 替换新程序的 `data`
5. 启动程序

数据、主题、语言设置会全部迁移。

## 数据安全

**数据永远保存在你的设备上。** 我们的服务器不会收到任何课程、学生或成绩信息。

三重保障：

1. **本地存储**：数据不离开电脑
2. **纯文本**：可以用记事本打开，不怕格式问题
3. **随时导出**：CSV、PDF、JSON 三种格式

## 版本兼容

- 从旧版本升级到新版本，数据格式自动迁移
- 从新版本回退到旧版本，可能丢失新版本的数据
- 测试版与正式版数据格式兼容

## 常见问题

**Q：备份文件有多大？**

A：一个 40 人的班级，一学期的数据大概 200 KB。加上照片可能到 2 MB。

**Q：可以把备份发到云盘吗？**

A：可以。数据是纯文本，不加密。如果担心隐私，可以自己压缩加密。

**Q：误删了数据能恢复吗？**

A：如果你开启过自动备份，去备份目录找最新的 `.zip`。如果没有开启，只能从系统回收站恢复。
