# 常见问题

## 基本使用

### 需要联网吗？

不需要。除了可选的新闻功能外，完全离线可用。

### 数据会上传吗？

不会。所有数据保存在本地 JSON 文件中。

### 支持 Mac 和 Linux 吗？

当前仅支持 Windows 10 与 11。跨平台版本在计划中。

### 怎么备份？

复制程序目录下的 `data` 文件夹即可，或使用内置的「备份数据」功能。

### 怎么卸载？

删除程序目录。数据文件也会一起删掉，零残留。

### 收费吗？

完全免费，MIT 开源协议。

## 功能相关

### 支持多少种语言？

20 种。包括简体、繁体、英、日、韩、法、德、西、俄、阿等。

### 可以导入 Excel 吗？

支持。学生名单与成绩都支持 CSV 与 Excel 导入。

### 有移动端吗？

暂时没有。灵动岛悬浮窗可以在桌面上提供类似移动端的即时信息。

### 支持打印吗？

支持。课表、座位表、成绩单都可以直接打印或导出为 PDF。

### 插件系统什么时候上线？

正在重新设计。请关注 [GitHub 仓库](https://github.com/Azurelab-Azure/myclassroom) 的更新。

## 数据安全

### 数据保存在哪里？

程序目录下的 `data` 文件夹：

| 文件 | 内容 |
|------|------|
| `config.json` | 设置 |
| `schedule.json` | 课程 |
| `students.json` | 学生 |
| `grades.json` | 成绩 |

### 换电脑怎么迁移？

把 `data` 文件夹复制到新电脑即可。详见 [备份与恢复](backup.md)。

### 数据会丢吗？

不会，只要你不主动删除。程序不会自动清理数据。

### 可以加密吗？

暂不支持。数据是纯文本，如果你需要加密，可以用压缩软件加密码。

## 安装与卸载

### 提示缺少 .NET 运行时怎么办？

从微软官网下载 .NET 10 Desktop Runtime，安装后再运行。

### 可以装在 U 盘吗？

可以。安装时选择 U 盘路径，数据会跟随程序目录。

### 卸载后数据还在吗？

默认保留。如果需要彻底清理，手动删除 `data` 文件夹。

## 性能

### 打开很慢怎么办？

首次启动会解压资源，大约 2-3 秒。之后启动在 1 秒内。

### 占用多少内存？

空闲状态约 80 MB，录入成绩时约 120 MB。

### 支持多少学生？

单个班级建议不超过 200 人。全校数据建议分班级管理。
