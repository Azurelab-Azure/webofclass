安装步骤

三步完成安装。

1

下载安装包

点击上方按钮下载 .exe 文件，约 45 MB。

2

双击运行

按提示完成安装。如果缺少 .NET 10 运行时会自动提示。

3

首次启动

程序会在安装目录生成数据文件，然后就可以使用了。

卸载方式

零残留，不留任何痕迹。

1

从 Windows 设置卸载

设置 → 应用 → 我的课表 → 卸载。

2

删除数据文件

删除程序目录下的 JSON 文件。如果需要保留数据请先备份。

数据与备份

所有数据保存在程序目录下的 JSON 文件中。复制该目录即可完成完整备份。

提示：数据永远保存在你的设备上。我们的服务器不会收到任何课程、学生或成绩信息。

备份方法

  • 直接复制整个程序目录到 U 盘或云盘
  • 或使用软件内置的「备份数据」功能

恢复方法

  • 把备份的 JSON 文件放回程序目录
  • 重启软件即可看到原来的数据
