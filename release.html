Release Notes

见证 PlanPeople 的每一次进化。最新的功能改进与底层优化都在这里。

v3.0.0 Test
2026.10
  • 【底层重构】全面抛弃旧版渲染引擎，拥抱 .NET 8 与 Avalonia 11。
  • 【极致轻量】发布包体积降至 38.8MB，彻底告别 Web 套壳臃肿。
  • 【性能飞跃】课表拖拽、页面切换达到原生 60FPS 绝对顺滑体验。
  • 【单文件发布】解压即用，无需手动安装 .NET 运行时环境。
  • 【警告】当前为演示框架版本，逻辑尚未完善，仅供极客测试评估。
v1.1.0
2026.08
  • 新增学生管理模块：支持名单导入、可视化座位表与 13 项个人档案。
  • 新增成绩分析看板：自动生成班级排名、及格率，支持导出 PDF。
  • 上线桌面灵动岛悬浮窗，实时显示当前课程与倒计时。
v1.0.0
2026.06
  • PlanPeople 首个正式版本发布。
  • 支持自定义排课（周次、单双周、特殊节次）。
  • 实现纯本地 JSON 数据存储，彻底杜绝服务器数据泄露风险。
